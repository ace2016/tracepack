# Commercial License

The parts of this repository under AGPLv3 (see [`LICENSING.md`](LICENSING.md) for the full
list) are free to run yourself, study, and modify. AGPLv3's one real condition is that if you
modify this code and run your modified version as a service other people use, you have to
publish your modified source to them.

A commercial license is a separate agreement with Spendmita Ltd (registered in England and
Wales, company number 17200525, ICO registration ZC140295), the company behind Tracepack,
that lifts that condition. It exists for anyone who wants to build on the AGPLv3 code without
being bound by it, for example:

- A hosted product built on Tracepack's workspace or extension code that you do not want to
  open source.
- A white label or reseller product built on this codebase.
- A marketplace or platform integration that embeds Tracepack's product code inside a closed
  commercial offering.
- Tracepack's own future hosted offering, if it needs terms different from what AGPLv3 gives
  the general public.

## What it does not cover

The Apache-2.0 packages (`evidence-core`, `evidence-sdk`, `template-engine`, `cli`,
`examples/`) never needed a commercial license to begin with. Apache-2.0 already lets anyone
build on them, closed source or not, at no cost and with no obligation back to Tracepack.
A commercial license is only relevant if you want to use the AGPLv3 product code outside
AGPLv3's terms.

## How to ask

This program does not exist yet as a packaged offering you can sign up for on your own;
there is no price list or signup flow today. If you want to talk about a commercial license,
email [licensing@tracepack.org](mailto:licensing@tracepack.org) with what you want to build
and which part of the codebase it touches. Terms are negotiated case by case for now.
